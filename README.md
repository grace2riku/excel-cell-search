# Excel Cell Search

Windows 11のデスクトップ版Excelを使い、指定された `.xlsx` の全シートを検索して、ヒットしたセルへのハイパーリンク一覧を出力するツールです。Python版 v1.2。

## 動作環境

- Windows 11、Python 3.12、デスクトップ版Microsoft Excel
- 初回セットアップ時のネットワーク接続（`pywin32` のインストール用）

PowerShellは使用しません。専用の `.venv` に依存ライブラリをインストールします。

## 使い方

1. このリポジトリをダウンロードして展開します。
2. `Setup.cmd` を実行します（初回のみ）。
3. Excelで入力用 `.xlsx` を作り、先頭ワークシートのB1〜B3を設定します。
4. 設定を保存して対象ファイルをExcelで閉じ、`Start.cmd` を実行します。
5. 入力用 `.xlsx` を選択し、完了後に出力ファイルを開きます。

| セル | 設定内容 | 例 |
| --- | --- | --- |
| B1 | 検索対象ファイルのフルパス | `C:\ExcelSearch\対象.xlsx` |
| B2 | 検索ワード | `abc` |
| B3 | 出力先ファイルのフルパス | `C:\ExcelSearch\検索結果.xlsx` |

出力先の親フォルダーを先に作成してください。既存の出力ファイルは全体を上書きします。

## 検索・出力仕様

- 全ワークシートを対象に、**大文字・小文字を区別した部分一致**で検索します。
- `abc` は `def/abc` にヒットし、`def/ABC` にはヒットしません。
- 数式セルはExcelで再計算した結果を検索します。
- 同じセルに複数回含まれていても、出力は1件です。
- 出力はA1に `No`、B1に `ハイパーリンク`、2行目以降に連番とセルへのリンクを記載します。
- 非表示シートも検索しますが、リンクで移動するには再表示が必要な場合があります。
- 数値・日付は表示形式ではなく内部の値を文字列化して比較します。
- Excelの1シートのハイパーリンク上限65,530件を超える場合は、結果を更新せずエラーにします。

詳しい操作方法・制限・トラブル対応は [取扱説明書](README.txt) を参照してください。

## テスト

Windowsではセットアップ後に `Test.cmd` を実行します。単体テスト6件と、実際のExcelを使用する結合テスト7件が実行されます。成功時は `Ran 13 tests` と `OK` が表示されます。

Pythonだけで実行する場合:

```sh
python -m unittest discover -s . -p 'test_*.py' -v
```

Windows以外ではExcel結合テストはスキップされます。開発環境で単体テスト6件の成功を確認し、利用者のWindows PCでv1.2の `Test.cmd` と `Start.cmd` の成功報告を受けています。
